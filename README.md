# Ross

Пример простого бота для размещения объявлений о продаже автомобилей во
ВКонтакте. Скрипт использует официальное API и публикует сообщения на стене
заданной группы.

## Требования
- Python 3.8+
- Библиотека `vk_api` (`pip install vk_api`)

## Использование
1. Создайте токен доступа сообщества во ВКонтакте и сохраните его.
2. Укажите токен и идентификатор группы через переменные окружения
   `VK_TOKEN` и `VK_GROUP_ID`.
3. Запустите скрипт:
   ```bash
   python vk_auto_sale_bot.py
   ```
   Сообщения из списка `posts` в файле будут опубликованы с задержкой между
   публикациями.

Автоматизация должна осуществляться в соответствии с правилами платформы.
Не используйте бота для спама.
